# Видеозвонок — простое приложение

## Как это работает
1. Оба человека открывают одну и ту же ссылку (адрес твоего сервера).
2. Каждый вводит одинаковый "код комнаты" (любое слово, придуманное заранее — например `barcelona-novgorod`).
3. Сервер сводит двоих в одной комнате и помогает браузерам договориться напрямую (WebRTC).
4. Дальше видео и звук идут напрямую между браузерами (P2P), сервер их не видит.

## Деплой на Render (пошагово)

1. Зайди на github.com, создай новый репозиторий (например `video-call-app`).
2. Залей туда все 3 файла из этой папки: `server.js`, `package.json`, и папку `public/` с `index.html` внутри.
   - Проще всего через веб-интерфейс GitHub: "Add file" → "Upload files", перетащи все файлы, сохраняя структуру папок.
3. Зайди на render.com, зарегистрируйся (можно через GitHub — это свяжет аккаунты).
4. На Render нажми "New" → "Web Service".
5. Выбери свой репозиторий `video-call-app`.
6. Настройки:
   - Build Command: `npm install`
   - Start Command: `npm start`
   - Instance Type: Free
7. Нажми "Create Web Service" — Render соберёт и запустит сервер (займёт пару минут).
8. Получишь ссылку вида `https://video-call-app-xxxx.onrender.com` — это и есть твой сайт для звонков.

## Важно
- При заходе после долгого простоя (бесплатный тариф "засыпает") первая загрузка займёт 30-50 секунд.
- Оба человека должны разрешить доступ к камере/микрофону в браузере.
- Работает лучше всего в Chrome/Safari/Firefox последних версий.
