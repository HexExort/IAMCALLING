# Звонки + чат + регистрация + push-уведомления

## Что нового по сравнению с прошлой версией
- Регистрация и вход (никнейм + пароль)
- Переписка с любым зарегистрированным пользователем, история хранится в базе данных (30 дней на бесплатном тарифе Render)
- Push-уведомления о новых сообщениях и звонках — приходят, даже если браузер закрыт (на iPhone — только если сайт добавлен на домашний экран)

## Шаг 2. Добавь базу данных на Render
1. В панели Render нажми "New" → "PostgreSQL".
2. Дай любое имя, выбери Free tier, создай.
3. После создания зайди в неё и скопируй "Internal Database URL" (или "External" — если сервис в другом регионе).
4. Зайди в свой Web Service (сайт со звонками) → вкладка "Environment" → добавь переменную:
   - `DATABASE_URL` = скопированная строка

После добавления переменных Render сам перезапустит сервис. В логах должно появиться `Database ready` и `Server running on port ...`.

## Как пользоваться
1. Оба человека заходят на сайт, регистрируются под любым никнеймом.
2. Каждый вводит никнейм собеседника, чтобы открыть с ним чат.
3. Можно писать сообщения — они сохраняются.
4. Кнопка "📹 Позвонить" запускает видеозвонок.
5. Если разрешить уведомления в браузере — при новом сообщении или звонке придёт push, даже если вкладка закрыта.

## Про iPhone
Push-уведомления на iPhone работают только если сайт добавлен на домашний экран:
Safari → кнопка "Поделиться" → "На экран «Домой»". После этого открывай сайт именно через иконку на экране, не через Safari напрямую — тогда уведомления будут приходить.

## Ограничения бесплатного тарифа
- Web Service "засыпает" после 15 минут простоя, первая загрузка после сна — 30-50 секунд.
- База данных PostgreSQL на free tier удаляется через 30 дней — если понадобится дольше, придётся создать новую базу или перейти на платный тариф (~$7/мес).
